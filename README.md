# 下班大作战 Office Escape

Phaser 3 + TypeScript + Vite 的俯视角像素办公室潜行游戏。原仓库仅含文字游戏 `index.html`，未发现 Netlify 配置、资源目录或后端。本次替换原游戏入口，新增独立游戏逻辑、渲染、测试和 Netlify 构建配置，未改变 Git 远端。

## 本地运行

要求 Node.js 22 或更新版本。

```sh
npm ci
npm run dev -- --port 5173
```

在浏览器打开开发服务器输出的地址即可开始。生产版本：`npm run build`，然后 `npm run preview`。

## 操作与规则

- WASD / 方向键、鼠标点击相邻地格，或手机方向按钮移动。
- 空格等待，Q 观察（不消耗游戏内时间），E 伪装。点击背包道具使用。
- 17:00 开始，每次有效行动消耗一分钟；同事求助额外消耗两分钟。18:00 未逃脱或真实经过五分钟则失败。
- NPC 随玩家行动自主推进，观察时停在当前状态，允许规划。朝向、视野、障碍、警觉及事件均影响后续行动。
- 连续进入视线依次经历注意、怀疑、确认；警觉达到 100 失败。脱离所有视线逐步恢复警觉。伪装会随行动衰减。
- 老板工作、巡逻、观察、怀疑、调查并返回办公室。同事 A 会求助，同事 B 连续看到异常会向老板报告。
- 金色小物资走近自动拾取。到右下角电梯逃脱；维修时需等待维护结束或使用门禁卡。
- 各难度的视野/警觉增长/巡逻频率/资源量不同。每局随机地图、NPC 初始位置与巡逻目标、道具种类和位置、事件时间偏移；事件还受位置、耳机与 NPC 状态影响。

| 难度 | 视野格数 | 基础警觉增长 | NPC 行动间隔 | 地图资源 |
| ---- | -------- | ------------ | ------------ | -------- |
| 简单 | 3        | 12           | 2 次行动     | 6        |
| 普通 | 4        | 18           | 1 次行动     | 5        |
| 困难 | 5        | 25           | 1 次行动     | 4        |
| 地狱 | 6        | 32           | 1 次行动     | 3        |

实际警觉增长还受到 NPC 类型、伪装、道具影响，变动原因记录在日志中。

## 道具

咖啡杯：伪装 100，6 回合降低暴露；文件夹：伪装 100，4 回合掩护；手机：老板转身接电话 4 回合；纸箱：4 回合降低暴露；门禁卡：解除维修锁；耳机：避免求助和来电铃声，6 回合加快警觉恢复。使用道具消耗一次行动。

## 评分、卡牌和保存

成功局：时间 40% + 潜行 30% + 行动效率 20% + 成就 10%。失败局最多 39 分。难度纪录独立保存，历史保留最近 50 局，图鉴、成就进度和设置保存在 LocalStorage。浏览器禁止存储时退化为当前会话存档，并显示提示。成绩卡可导出 PNG。

十张卡牌均有确定条件，直接达成直接解锁，无抽奖逻辑。完整条件见图鉴及 `src/achievements.ts`。特殊成就条件只依赖游戏状态，不依赖随机数。

## 验证

```sh
npm test
npm run build
# 首次准备浏览器（本机已有 Chromium 则省略）
npx playwright install chromium
npm run test:browser
# 云环境已有系统 Chromium：
CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
```

引擎测试覆盖三图通路、巡逻通路、方向视线和遮挡、免费观察、碰撞、自主巡逻、四难度差异、六道具、十事件、发现与失败、五分钟硬上限、十二种地图/难度组合的完整逃脱、确定性卡牌与评分权重。浏览器测试通过真实键盘、触控与鼠标操作，验证完整逃脱、PNG 下载、刷新后战绩/卡牌保留、移动布局和超时结算。

## Netlify

`netlify.toml` 配置 Node 22、`npm run build`、发布目录 `dist`。纯前端，无服务器、数据库或密钥要求。可连接原 GitHub 仓库，或上传 `dist` 产物。仓库中没有 Netlify 站点 ID 或现有在线站点地址；本地构建通过不等于远端部署已完成。本次不声称已经发布生产站点。

## 结构

- `src/engine.ts`：地图、寻路、视线、行动、难度、NPC、事件、道具、胜负。
- `src/achievements.ts`：确定成就条件和评分。
- `src/main.ts`：Phaser 渲染、输入、界面、存档、结算、战绩卡。
- `src/style.css`：手机/桌面响应式界面。
- `tests/engine.test.ts`、`tests/browser.spec.ts`：逻辑和浏览器验收。
- `playwright.config.ts`、`tsconfig.json`、`package.json`、`package-lock.json`、`netlify.toml`：工具与部署配置。

## 当前边界

这是行动制潜行首版，NPC 随有效行动推进，并非实时自由移动。像素角色和家具由代码绘制，无外部素材或 Emoji 角色。五分钟上限已实现；约三分钟的平均游玩目标仍需真人试玩和平衡验证。尚未进行真实手机硬件、Safari 和 Netlify 线上验收；浏览器测试使用桌面 Chromium 与触控模拟。Phaser 完整包较大，后续可根据真实设备测速做加载优化。没有云端存档、账号或全球排行榜。
